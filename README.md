# Dictionary
Dictionary app with online translator for learning languates. 

[Deployment on Github Pages](https://self-related.github.io/dictionary/)

## Features
- Translate words and phrases
- Manual output edit
- Manage dictionaries
- Sort dictionary entries by categories
- Blur all translations, click to reveal
- Persist all data in local storage
- Different accent color schemes
- Automatic and manual dark/light themes
- Adaptive design for different screens

## Tech stack
- TypeScript
- React + CSS modules
- Redux
- Redux Query
- Vite (bundler)
- Google Translate API

## Run
``npm run dev``

## Build
``npm run build``
